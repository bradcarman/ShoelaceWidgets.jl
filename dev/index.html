ShoelaceWidgets.jl

ShoelaceWidgets.jl provides Julia bindings for Shoelace web components, enabling you to create interactive web UIs in Julia using the Bonito.jl framework.

Installation

using Pkg
Pkg.add("ShoelaceWidgets")

Quick Start

To get started with ShoelaceWidgets.jl you simply need to include Bonito.jl. The following example shows how to provide an input box.

using ShoelaceWidgets
using Bonito

# Create an input widget
input = SLInput(""; label="Enter text:", placeholder="Type something...", help="help text can be in <strong>HTML</strong>")

# Create a Bonito app
app = App() do session
    input
end
help text can be in HTML

Every widget loads Shoelace itself: the first one on a page adds the Shoelace scripts and styles to the document head, so an app can return a widget directly without any setup.

Dark Mode

By default the widgets follow the browser/OS color scheme: both Shoelace themes are loaded, each gated on prefers-color-scheme, so changing the system theme reskins a running page without a reload. Place an SLTheme anywhere in the app to pin one instead:

app = App() do session
    DOM.div(
        SLTheme(:dark),  # or :light, :auto is the default
        input
    )
end

Shoelace themes only define CSS custom properties, they never style the page itself, so ShoelaceWidgets.jl also sets the document background and text color from those tokens the way shoelace.style does. Those rules use :where(body), which has zero specificity, so any styling of your own overrides them.

More Examples

Button

Create a button with click handling:

# Create button
btn = SLButton("Click Me"; variant="primary")

# Set up click handler
on(btn.value) do _
    btn.loading[] = true
    println("Button was clicked!")
    sleep(2)
    btn.loading[] = false
end

app = App() do session
    btn
end
Click Me

Setting href renders the button as a link, opening a URL instead of firing a click handler:

link_btn = SLButton("Visit Julia"; href="https://julialang.org/", target="_blank", rel="noreferrer noopener")

app = App() do session
    link_btn
end
Visit Julia

Dropdown

Create a dropdown select:

# Create select widget
select = SLSelect(["Small", "Medium", "Large"]; label="Choose size", index=1)

on(select.index) do i
    println("Selected value: $(select.value)")
end

app = App() do session
    select
end
SmallMediumLarge

Progress Bar

Create a progress bar with reactive updates:

# Create progress bar
progress = SLProgressBar(0.0; label="Loading", height="20px")

# Simulate progress updates
@async begin
    for i in 0:10:100
        sleep(0.5)
        progress.value[] = i
    end
end

app = App() do session
    progress
end

You can also show and hide progress bars dynamically:

# Create initially hidden progress bar
progress = SLProgressBar(50.0; visible=false, label="Background task")

# Show the progress bar
progress.visible[] = true

# Hide it again
progress.visible[] = false
false

Alert

Create an alert to display information...

alert = SLAlert(DOM.div(DOM.strong("This is super informative"), DOM.br(), DOM.div("You can tell by how pretty the alert is.")))
app = App() do session
    alert
end

Available Components

ShoelaceWidgets.jl provides Julia wrappers for common Shoelace components:

Web Components

  • SLInput - Text input fields with various types
  • SLSelect - Dropdown selection components
  • SLButton - Interactive buttons
  • SLCheckbox - Checkbox controls
  • SLTextarea - Multi-line text input
  • SLRadio / SLRadioGroup - Radio button controls (also available as SLListItem / SLList that provide different selection styling )
  • SLProgressBar - Progress indicators and loading bars
  • SLDialog - Dialog window
  • SLAlert - Alerts used to display important messages inline

UI Elements

  • sl_tab_group, sl_tab, sl_tab_panel - Tab navigation
tabs = sl_tab_group(

    sl_tab("Tab 1"; slot="nav", panel="tab1"),
    sl_tab("Tab 2"; slot="nav", panel="tab2"),


    sl_tab_panel(DOM.div("Hello World"); name="tab1"),
    sl_tab_panel(DOM.div("Goodbye"); name="tab2")
)

app = App() do session
    tabs
end
Tab 1Tab 2
Hello World
Goodbye
  • sl_tag - Tags for labels and categories
  • sl_format_date - Date formatting
  • sl_spinner - Loading indicators
  • sl_icon - Icons from the Shoelace Icon Library
  • sl_tooltop - Tooltip display during mouse hover 
button = SLButton("Test")

app = App() do session
    sl_tooltip(button; content="click me")
end
Test
  • sl_copy_button - send contents of value to the clipboard
app = App() do session
    DOM.div("Copy Button:", sl_copy_button(;value="clipboard contents"))
end
